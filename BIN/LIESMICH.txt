BIN - optionale Zusatzprogramme (werden NICHT ueber GitHub verteilt)

USMT (fuer das Modul "Windows-Einstellungen (USMT)" - auch noetig, wenn beim Restore
  auf einem neuen PC das Profil des Benutzers angelegt werden soll; ohne USMT muss sich
  der Benutzer vorher einmal am Ziel-PC anmelden):
  - Windows ADK installieren (Feature "User State Migration Tool") ODER
  - den Ordner "amd64" aus
      C:\Program Files (x86)\Windows Kits\10\Assessment and Deployment Kit\User State Migration Tool\
    hierher kopieren:  BIN\USMT\amd64\scanstate.exe, loadstate.exe, ...
  - oder in Config\settings.json "UsmtPath" setzen.
  HUMig sucht in dieser Reihenfolge: UsmtPath, BIN\USMT\amd64, BIN\USMT, ADK-Standardpfad.
  Fuer Windows 11 die USMT-Version aus dem aktuellen ADK verwenden.
